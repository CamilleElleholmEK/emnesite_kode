# Emnesite

A longer exercise from my first semester at multimediadesign at Erhvervsakademi København.

## Description

A site based on a subject of our choosing. I chose to make a "sortable" database of episodes from a danish podcast. I was very ambitious, and tried to implement things that we hadn't learned yet.

Therefore the site is not at all functional and is only meant to be viewed with the school context in mind.
